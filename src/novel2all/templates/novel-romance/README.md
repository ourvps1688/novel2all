# 言情小说模板

novel2all 项目模板 —— 现代都市言情。

## 项目结构

```
{project_root}/
├── _tracking-state.json
├── 创作设定.md
├── 设定/
│   ├── 文风.md
│   ├── 世界观/
│   └── 角色/
├── 大纲/
├── 正文/
└── 拆文库/
```

## 初始创作设定模板

```markdown
# 创作设定

## 项目名
你的小说名

## 题材
现代都市言情

## 文风
（建议：清新细腻 / 虐心催泪 / 甜宠 / 复仇）

## 目标
- 章节数：80-120
- 字数：80-120 万字

## 主角
- 女主：年龄、职业、性格、背景
- 男主：年龄、职业、性格、背景

## 故事梗概
（一段话讲清核心冲突）

## 主线冲突
（如：身份悬殊 / 家族恩怨 / 误会 / 复仇）

## 主线剧情节拍
1. 相遇（第 1-5 章）
2. 相知（第 6-30 章）
3. 冲突（第 31-60 章）
4. 高潮（第 61-80 章）
5. 结局（第 81-120 章）
```

## 推荐模型

- 主写作：Claude Sonnet（细腻 / 共情强）
- 拆书：Claude Sonnet
- 一致性检查：Haiku（快）
- 提取：Haiku

## 推荐写作流程

1. `novel2all setup --name "..." --genre "言情" --style "..."`
2. 写大纲：编辑 `大纲/大纲.md` + `大纲/卷纲_第1卷.md`
3. 写细纲：每章一个文件 `大纲/细纲_第NNN章.md`
4. 写正文：`novel2all write chapter 5`
5. 审查：`novel2all write chapter 5 --review`
6. 去 AI 味：`novel2all deslop 正文/第5章.md`
