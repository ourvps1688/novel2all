novel2all 项目模板 —— 玄幻 / 仙侠长篇。

## 项目结构

（同言情模板）

## 初始创作设定模板

```markdown
# 创作设定

## 项目名
你的小说名

## 题材
玄幻 / 仙侠

## 文风
（建议：热血升级 / 慢热升级 / 黑暗向 / 轻松）

## 目标
- 章节数：400-1500
- 字数：150-500 万字

## 修炼等级
（如：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 仙人）

## 主角
- 出身（草根 / 世家 / 宗门弟子 / 废柴逆袭）
- 金手指（戒指老师 / 系统 / 重生记忆 / 血脉）
- 核心动机（复仇 / 求道 / 保护某人 / 飞升）

## 世界观
- 地理（大陆 / 城市 / 秘境）
- 势力（宗门 / 散修 / 妖族 / 魔道 / 天庭）
- 资源（灵石 / 法宝 / 丹药）

## 力量体系
- 战气 / 魔法 / 灵力
- 境界划分（每个境界的特征）
- 突破条件

## 主线冲突
（如：道统之争 / 飞升之谜 / 灭世危机 / 种族战争）

## 主线剧情节拍
1. 起步（1-50 章）：废柴开局 + 金手指 + 入门宗派
2. 崛起（51-200 章）：宗门大比 + 外出历练 + 感情线
3. 风云（201-500 章）：跨宗派争斗 + 远古遗迹 + 道侣情深
4. 渡劫（501-800 章）：魔道入侵 + 天庭之谜 + 飞升之战
```

## 推荐写作流程

1. **力量体系先行** —— 编辑 `设定/世界观/力量体系.md`，每个境界详细描述
2. **主角档案** —— 编辑 `设定/角色/主角.md`，包含金手指完整机制
3. **起点规划** —— 第 1 章要明确金手指触发 + 第一个小目标
4. **每 50 章一个境界突破** —— 不要让升级过快或过慢
5. **每 100 章一个新地图** —— 保持新鲜感
