# 短篇小说模板

novel2all 项目模板 —— 知乎盐言 / 番茄短篇 / 七猫短篇。

## 项目结构

```
{project_root}/
├── _tracking-state.json
├── 创作设定.md
├── 设定/
├── 大纲/
│   ├── 大纲.md           # 故事核 + 8 节结构
│   └── 小节大纲.md       # 8 节小节大纲
├── 正文/
│   └── 正文.md           # 完成的短篇
└── 拆文库/
```

## 初始创作设定模板

```markdown
# 创作设定

## 项目名
短篇标题

## 平台
知乎盐言 / 番茄短篇 / 七猫短篇

## 情绪类型
虐 / 甜 / 治愈 / 爽 / 反转 / 复仇

## 字数
3000-8000 字

## 故事核
（一句话讲清核心反转）

## 主要人物
- 主角：年龄、性格、动机
- 反派/配角：核心冲突来源

## 8 节结构
1. 起势（建立）
2. 钩子（引发好奇）
3. 转折（第一次反转）
4. 升级（矛盾加深）
5. 危机（最强张力）
6. 反转（核心揭秘）
7. 收束（情感落地）
8. 余韵（留白 / 钩尾）

## 风格参考
（参考哪些短篇）
```

## 推荐写作流程

1. `novel2all setup --name "..." --genre "短篇-言情"`
2. **一句话故事核** —— 这是最重要的！先确定核心反转
3. **8 节小节大纲** —— 编辑 `大纲/小节大纲.md`
4. **逐节写作** —— 每节保持情绪曲线
5. **精修** —— 去 AI 味 + 钩子强化
6. **平台适配** —— 检查字数 / 风格 / 标题
