## 4. 路由架构（V0.23 最终态）

```
┌─────────────────────────────────────────────────────────────┐
│ 调用方 (pipeline / extractor / verifier)                     │
│   llm.complete(task=TaskType.WRITING)                       │
│   llm.complete_structured(task=TaskType.EXTRACTION)          │
│   llm.complete_structured(task=TaskType.CONSISTENCY)         │
└──────────────────┬──────────────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────────────────┐
│ LLMProvider                                                  │
│   _resolve_model(task=...) → ModelRouter.select(task)        │
│   _get_extra_body(model) → THINKING_CONTROL.get(model)       │
└──────────────────┬──────────────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────────────────┐
│ ModelRouter                                                  │
│   select(WRITING)       → deepseek/deepseek-v4-pro           │
│   select(EXTRACTION)    → deepseek/deepseek-flash            │
│   select(CONSISTENCY)   → deepseek/deepseek-flash            │
│   select(SUMMARIZATION) → deepseek/deepseek-flash            │
│   select(COVER)         → deepseek/deepseek-flash            │
│   cost_estimate(task, prompt, completion, cache_hit=False)   │
│     → 自动选 off-peak/peak 时段 + cache_hit/miss 价格       │
└──────────────────┬──────────────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────────────────────────┐
│ LiteLLM (litellm.acompletion)                               │
│   extra_body = {"thinking": {"type": "disabled"}} (自动注入)│
│   model = "deepseek/deepseek-v4-pro" (默认)                 │
└─────────────────────────────────────────────────────────────┘
```

## 5. 50 章小说真实成本（基于 benchmark）

**假设**：每章 5 个 LLM 调用（WRITING + EXTRACTION + CONSISTENCY_PRE + CONSISTENCY_POST + SUMMARIZATION）

| 方案 | 单章总成本 | 50 章总成本 |
|---|---|---|
| **全 flash** | ¥0.0070 | **¥0.35** |
| **混合（WRITING v4-pro + 其他 flash）** | ¥0.0224 | **¥1.12** |
| 全 v4-pro | ¥0.0250 | ¥1.25 |

**对比**：
- 纯 DeepSeek 直连 + 全 flash：**¥0.35**（最小化成本）
- 推荐路由（WRITING v4-pro）：**¥1.12**（能力与成本平衡）
- 全 v4-pro：¥1.25（边际收益不值得）

**时段优化**（避开高峰可再省 50%）：
- 凌晨批处理：100% off-peak → ¥0.56（混合路由）

## 6. 关键技术细节

### 6.1 DeepSeek 双模型分工

| 维度 | flash（DeepSeek-V4.1-Flash） | v4-pro（DeepSeek-V4-Pro-0813） |
|---|---|---|
| 输入 cache hit off-peak | **¥0.02/M** | ¥0.15/M |
| 输入 cache miss off-peak | ¥1.00/M | ¥4.50/M |
| 输出 off-peak | ¥4.00/M | ¥13.50/M |
| peak 倍数 | ×2 | ×2 |
| Context | 1M | 1M |
| Max output | 384K | 384K |
| Thinking | 默认关（我们强制关） | 默认开（我们强制关） |

### 6.2 thinking 控制

```python
THINKING_CONTROL = {
    "deepseek/deepseek-v4-pro": {"thinking": {"type": "disabled"}},
    "deepseek/deepseek-flash": {"thinking": {"type": "disabled"}},
}
```

**关键发现**（benchmark 实测）：
- v4-pro 默认 thinking 模式 → 30.52s 输出 0 字（reasoning 耗光 token）
- 加 `thinking:disabled` → 7.65s 输出 1232 字（正常）

### 6.3 is_peak_hour 实现

```python
def is_peak_hour() -> bool:
    """DeepSeek 高峰：周一至周五 9:00-12:00、14:00-18:00 (北京时间)"""
    # 优先 zoneinfo.ZoneInfo("Asia/Shanghai")
    # Fallback: timezone(timedelta(hours=8))  # Windows 找不到 tzdata
    if now.weekday() >= 5:
        return False
    hour = now.hour
    return (9 <= hour < 12) or (14 <= hour < 18)
```
