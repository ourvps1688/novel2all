# 导演注意力

应用内注意力提醒（Director Attention）是自动导演暂停、等待确认或需要你处理时的统一入口，取代了原先独立的「导演跟进」页面。它不是一个单独的页面，而是分布在工作台的三个位置：

- 导航栏注意力角标：铃铛图标常驻显示还有几本小说需要你处理，刷新页面也不会丢失。
- 顶部全局横幅（GlobalDirectorAttentionBanner）：需要恢复或等待审批的书会自动出现在页面顶部；点「收起」只隐藏当前会话，刷新后会重新出现。
- 创作中枢的「下一步」：打开某本书的创作中枢，若该小说处于需要恢复态，会给出直达恢复入口的动作。

当自动导演停住（例如等待方向选择、等待角色确认、卷战略就绪、章节批次就绪或等待重新规划）时，不再需要去某个固定页面查看，而是通过上述注意力提醒直接看到暂停原因，并一键进入对应的来源页面（小说页、章节页、自动导演来源页等）继续、重试或重规划。

任务中心和运行记录负责展示后台任务的事实状态与来源跳转；真正的恢复、重试、继续动作留在能呈现完整创作上下文的来源页面里完成。
