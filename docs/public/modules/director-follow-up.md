# 导演跟进

导演跟进能力保留在运行记录里。自动导演停下时，先从运行记录进入对应任务，再在来源页面处理。

## 从哪里进入

- 查看自动导演进度、暂停原因、恢复入口：打开「运行记录」（`/tasks`），进入对应导演任务查看详情。
- 核对后台任务状态、错误信息、来源页面入口：同一「运行记录」页面，只读查看，不在这里重试或恢复。
- 实际恢复、重试、继续：回到通知所指的来源页面（如小说页、章节页、自动导演创建页）操作。

## 常见下一步

| 你想做的事 | 去哪里 |
| --- | --- |
| 看导演任务是否暂停、为什么暂停 | 运行记录 → 对应任务详情 |
| 确认方向、角色或卷规划 | 小说基础信息页、角色候选页、卷规划入口 |
| 重试失败任务或继续章节 | 运行记录核对事实后，回到来源页面操作 |
| 处理需要重规划的质量问题 | 来源页面按阶段恢复 |

## 和运行记录的关系

运行记录负责事实：后台命令是否排队、运行、失败、待恢复或完成，并提供来源页面入口；它不执行恢复或重试。需要操作时，回到通知或运行记录所指的来源页面。

## 新手建议

如果不理解暂停文案，不要手动清理数据。先看运行记录最新状态，再回到小说页确认基础信息和候选项。大多数暂停都可以通过确认、重试或继续入口恢复。
