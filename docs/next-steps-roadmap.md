## 8. 风险与缓解

| 风险 | 影响 | 概率 | 缓解 |
|------|------|:----:|------|
| **LLM API 价格变动** | 路由决策过时 | 🟢 低 | 季度 benchmark 自动重测（V0.52 可加） |
| **Redis / SQLite 库大版本** | 接口破坏 | 🟡 中 | 锁版本在 pyproject.toml + 季度升级 |
| **Cache 多 region 一致性** | 数据冲突 | 🟡 中 | V0.56 用 CRDT + 最终一致 |
| **Web UI 性能瓶颈** | 大项目卡顿 | 🟡 中 | B3+B4 加分页 + 虚拟滚动 |
| **CI 资源成本**（15 jobs × 多 OS） | 月成本上升 | 🟢 低 | 优化为 8 jobs，关键矩阵保留 |

## 9. 资源需求

### 9.1 人力

- **单人全栈**：~4 周完成主线 A+B 全部 + 主线 C 部分（按 6.1-6.4）
- **2 人分工**：前端专注 WebUI（V0.30 / B3-B5），后端专注 Cache + LLM（A+C）

### 9.2 API / 服务成本

- **LLM API**（50 章小说测试）：~¥1.5/月（DeepSeek 双模型）
- **Redis 服务器**（如启用 V0.45）：~$5/月（云 Redis）
- **CI 资源**：GitHub Actions 免费层（够用）

### 9.3 工具

- **Docker Desktop**：本地 Redis 测试（用户装机后可启用）
- **真实 Redis 7**：`docker run -d -p 6379:6379 redis:7-alpine`
