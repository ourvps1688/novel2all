# novel2all V1.0 GA — Docker 部署指南

> **版本**：V1.0 GA（2026-09-14）
> **目标读者**：DevOps / 运维 / 个人部署
> **预计阅读**：5 分钟

---

## 1. 前置要求

- Docker 20.10+
- Docker Compose 1.29+（或 Docker Desktop 4.x+）
- LLM provider API key（DeepSeek / Anthropic / OpenAI / minimax 任一）
- 推荐：域名 + HTTPS（生产环境必需）

---

## 2. 快速部署

### 2.1 准备环境变量

```bash
# 必填：admin 凭证
export NOVEL2ALL_ADMIN_USER=admin
export NOVEL2ALL_ADMIN_PASS=<强密码，建议 ≥ 16 字符>

# 必填：至少一个 LLM provider
export DEEPSEEK_API_KEY=sk-xxxxx        # 推荐（便宜 + 中文强）

# 可选
export ANTHROPIC_API_KEY=sk-xxxxx       # Claude Sonnet
export OPENAI_API_KEY=sk-xxxxx          # GPT-4o
export MINIMAX_API_KEY=xxxxx            # minimax-M3（V0.23.5）
```

### 2.2 启动

```bash
# 克隆仓库
git clone https://github.com/ourvps1688/novel2all.git
cd novel2all

# 启动（包含 Redis cache backend）
docker-compose up -d

# 查看日志
docker-compose logs -f web

# 访问 http://localhost:8000
# 用 admin / your_password 登录
```

## 4. 配置

### 4.1 环境变量

| 变量 | 必填 | 默认 | 说明 |
|------|:---:|------|------|
| `NOVEL2ALL_ADMIN_USER` | ✅ | "" | Admin 用户名 |
| `NOVEL2ALL_ADMIN_PASS` | ✅ | "" | Admin 密码（≥ 16 字符）|
| `NOVEL2ALL_LLM_CACHE_ENABLED` | ❌ | true | 是否启用 cache |
| `NOVEL2ALL_LLM_CACHE_BACKEND` | ❌ | memory | memory/sqlite/redis/json |
| `NOVEL2ALL_LLM_CACHE_TTL` | ❌ | 86400 | 缓存 TTL（秒）|
| `NOVEL2ALL_LLM_CACHE_MAX_SIZE` | ❌ | 256 | LRU 上限 |
| `NOVEL2ALL_LLM_CACHE_REDIS_URL` | ⚠️ | - | Redis URL（backend=redis 时必填）|
| `ANTHROPIC_API_KEY` | ⚠️ | - | Anthropic API key |
| `OPENAI_API_KEY` | ⚠️ | - | OpenAI API key |
| `DEEPSEEK_API_KEY` | ⚠️ | - | DeepSeek API key（推荐）|
| `MINIMAX_API_KEY` | ⚠️ | - | minimax-M3 API key |

### 4.2 持久化数据

docker-compose 自动挂载两个 named volume：

| Volume | 用途 | 大小 |
|--------|------|-----:|
| `novel2all-data` | auth.db / sessions.db / cache.db / adaptive_routing.db | ~10MB / 100 章 |
| `redis-data` | Redis AOF 持久化文件 | ~50MB / 100 章 |

**手动备份**：

```bash
docker-compose exec -T redis redis-cli BGSAVE
docker run --rm -v novel2all_novel2all-data:/data -v $(pwd):/backup \
    alpine cp /data/auth.db /data/sessions.db /data/cache.db /data/routing.db /backup/
```

## 5. 升级

```bash
# 1. 备份
docker-compose exec -T redis redis-cli BGSAVE
docker run --rm -v novel2all_novel2all-data:/data -v $(pwd):/backup alpine sh -c 'cp /data/* /backup/'

# 2. 拉最新代码
git pull origin main

# 3. 重新构建 + 启动
docker-compose build --pull
docker-compose up -d

# 4. 验证
docker-compose logs -f web
curl http://localhost:8000/api/cache/stats
```

## 6. 监控

### 6.1 健康检查

docker-compose 自动检查 `/api/cache/stats` 端点。

```bash
docker-compose ps
# 期望: web 服务 "Up" + "(healthy)"
```

### 6.2 关键指标

```bash
# Cache hit rate
curl http://localhost:8000/api/cache/stats | jq .hit_rate

# Prompt prefix cache
curl http://localhost:8000/api/cache/prompt-stats | jq .hit_rate, .cost_saved_cny

# 当前用户
curl -b cookies.txt http://localhost:8000/api/auth/me
```

### 6.3 日志位置

```bash
# Web 应用日志
docker-compose logs -f web

# Redis 日志
docker-compose logs -f redis
```

## 8. 故障排查

### 8.1 容器启动失败

```bash
docker-compose logs web
# 常见错误：
# - NOVEL2ALL_ADMIN_PASS 未设置（compose 启动失败）
# - Redis 连接失败（检查 depends_on 健康检查）
```

### 8.2 LLM 调用失败

```bash
# 检查 API key 是否正确加载
docker-compose exec web env | grep -E 'API_KEY|ADMIN'

# 检查 cache 是否启用
docker-compose exec web python -c "from novel2all.core import LLMConfig; print(LLMConfig())"
```

### 8.3 性能问题

```bash
# 查看 cache hit rate
curl http://localhost:8000/api/cache/stats | jq .

# 启用 Redis 后端（替代 memory）
# 修改 docker-compose.yml: NOVEL2ALL_LLM_CACHE_BACKEND=redis
docker-compose restart web
```

## 9. 卸载

```bash
# 停止 + 删除容器 + 删除数据（不可逆！）
docker-compose down -v

# 删除镜像
docker image rm novel2all-web
```

## 10. 进阶

### 10.1 反向代理示例（nginx）

```nginx
server {
    listen 443 ssl http2;
    server_name novel.example.com;

    ssl_certificate /etc/letsencrypt/live/novel.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/novel.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
