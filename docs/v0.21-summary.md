## 1. 目标

解决 novel2all 在 V0.20 留下的"漏掉历史"问题——LLM 长篇写作中无法记住 50+ 章前的角色/伏笔/事件。

**V0.21 主旋律**：端到端跑通"最小可用闭环"，让长篇写作 + 长记忆真正可工作。

**范围（ROADMAP 已定）**：
- L4 事件检索（向量数据库）
- L3 早期章节压缩摘要
- 完整 skill pipeline + LLM 真写
- Web SSE 流式输出
- 端到端验证

## 2. 关键决策

| # | 决策 | 理由 |
|---|---|---|
| 1 | chromadb → TF-IDF → keyword 三层降级 | 沙箱/Windows runner 上 chromadb DLL 缺失，优雅降级而非失败 |
| 2 | chromadb force_mode 优雅降级（非 assert） | 测试与生产环境差异不阻断 pipeline |
| 3 | 真实 LLM 默认 DeepSeek | 便宜 + 中文强 + OpenAI 兼容 API |
| 4 | verifier 区分 critical / warning / info | 之前所有"建议"都判 critical 导致无法写 |
| 5 | SSE 用 asyncio.Queue 桥接 sync callback | stream_callback 签名同步，需 yield 到 async generator |
| 6 | run_pipeline() finally put sentinel(None) | 异常时也能让 event_stream 退出 |
| 7 | 字符类 ignore 规则完全删除 | 短名模式误伤 `pipeline.py` 等正常文件 |
| 8 | classic PAT + `repo` scope | fine-grained PAT 即便 owner 也不能读 logs API |

## 5. 关键能力

### 5.1 5 层长记忆
- **L1 核心设定**（永远加载）：世界规则、风格锚点
- **L2 角色状态**（按需）：性格、位置、情绪、最后更新章节
- **L3 章节摘要**（滑动窗口）：1-10 全量、11-30 每 5 章合并、31+ 每 10 章合并
- **L4 事件检索**（向量）：chromadb + TF-IDF + keyword 三层降级
- **L5 知识图谱**（待 V0.22）

- **CLI**：`novel2all write chapter 1` 调真 LLM 写一章
- **Web SSE**：`/api/write/stream` 实时推送 LLM chunk 到前端
- **verifier**：pre-write + post-write critical/warning/info 三级分类

### 5.3 UX 面板
- 章节详情弹窗（点击查看完整内容）
- 角色卡片网格（按最近更新排序，dead 状态标识）

- 已写章节列表（自动刷新）

## 8. 关键技术经验

### 8.1 GitHub Actions
- **classic PAT** 才能读 logs API（fine-grained 即便 owner 也 401）
- 跟随重定向时**不要带 Authorization** header（S3 blob 用 query-string 签名）
- GitHub 30 分钟 URL 过期，需要快速 fetch

### 8.2 chromadb 三平台差异
- 沙箱 Windows ❌（chroma-rust DLL 缺失）
- Linux/macOS ⚠️（onnxruntime 偶发失败）
- Windows runner ✅ 但**句柄不释放**（wipe_disk 需容错）

### 8.3 litellm 1.100+ 变化
- 需要 `deepseek/` 前缀（不能只 `deepseek-chat`）
- 沙箱网络代理破坏 Bearer → 模块加载时 `_strip_proxy_env()`

### 8.4 ruff check vs ruff format
- CI 两个**独立**跑，本地必须都通过
- GitHub Actions 装的 ruff 比本地新，I001 import 排序更严
- 需加 `known-first-party` + `.gitattributes` 强制 LF 行尾

### 8.5 TestClient 异步坑
- run_pipeline() 异常时**也必须 put sentinel(None)**，否则 event_stream 阻塞
- `asyncio.Queue` 桥接 sync `stream_callback` → async generator

### 8.6 .gitignore 字符类陷阱
- 短名模式（8-12 字符）会误伤 `pipeline.py` 等正常 Python 文件
- 临时文件用 **Python 脚本**删除（safe-delete 拦 PowerShell `Remove-Item`）
