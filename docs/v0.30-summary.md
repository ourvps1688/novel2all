## 2. 关键决策（基于一手数据 + 真实调用）

| # | 决策 | 数据来源 |
|---|------|---------|
| 1 | **WebUI E2E 必须用真实 chromium 浏览器**（而非 TestClient） | V0.30.5：htmx-sse + Alpine.js 跨域事件分发，TestClient 无法捕获 JS 错误 |
| 2 | **Playwright 安装仅在 ubuntu + windows 跑**（macos 用 `[chromium]` 默认） | CI 6 个 test job × 540MB = 3GB 带宽，拆独立 e2e job（ubuntu + windows） |
| 3 | **Pipeline 取消走 asyncio.Task.cancel() + CancelledError**（而非关闭连接） | 测试：SSE 关闭只断开响应，pipeline_task 继续运行浪费 token |
| 4 | **partial 内容保存到 output_path**（而非 `.partial.md` 副本） | V0.32 验证：partial 即"已写好的部分"，下次接续无需副本 |
| 5 | **接续 prompt 显式说"已有部分（不要重复）"** | LLM 行为测试：90%+ 会接续而非重复，加 instruction 后几乎 100% |
| 6 | **Cache 后端分 MemoryLRU + JSONFile 两层**（不分 SQLite） | V0.33：JSON 够简单 + 无新依赖 + 1.28MB 可加载；SQLite 复杂但收益小 |
| 7 | **JSONFileBackend 启动时过滤过期 + atomic rename** | temp + os.replace 防部分写入；TTL 检查避免返回 stale |
| 8 | **跨进程文件锁用 fcntl (POSIX) + msvcrt (Windows) + 降级** | V0.37：平台锁不能跨 OS（POSIX↔Windows 不互斥），单 OS 内 100% 安全 |
| 9 | **V0.35 benchmark 推翻 V0.27 推荐**：WRITING 切回 deepseek-flash（minimax 字数持平但贵 2.5x） | 16 真实调用：minimax 2713 字 vs flash 2726 字（差异 < 0.5%） |
| 10 | **AI 操作"不直接改文件"原则**：rewrite/insert 端点只返回 LLM 结果，前端 modal 预览，用户点应用才调 /save | V0.38：防止 LLM 输出错误直接破坏章节；保留用户主动权 |

### 3.9 V0.37 Cache 跨进程文件锁 — `4dd9c40` + 2 fix

- `JSONFileBackend._save()` 用 `with CacheLock(self._path):` 包裹
- `stats()` 加 `lock_backend` 字段

**CI 反复修**：
1. `4dd9c40` 初版：CI 失败（4 个 POSIX job）
2. `2ea1418` fix multiprocess 测试（subprocess cwd 不一致）

### 4.2 Pipeline 状态机（V0.32 最终态）

```
                  ┌─ 用户: 点击「开始写（流式）」
                  ↓
              [running] ──SSE: chunk──→ 实时渲染 + appendChunk()
                  │
                  ├── 用户: 点击「🛑 停止」
                  │       ↓
                  │   [cancelling]
                  │       ↓
                  │   task.cancel() → CancelledError
                  │       ↓
                  │   保存 partial → output_path
                  │       ↓
                  │   SSE: cancelled 事件
                  │       ↓
                  │   [cancelled] → 显示「已保存 N 字」
                  │       │
                  │       ├─ 用户: 「▶️ 继续写」
                  │       │       ↓
                  │       │   POST resume_from_chars=N
                  │       │       ↓
                  │       │   pipeline(resume_from_chars=N)
                  │       │       ↓
                  │       │   加载 partial[:N] + 注入 prompt
                  │       │       ↓
                  │       │   LLM 续写 (不再重复 partial)
                  │       │       ↓
                  │       │   content = partial + 续写
                  │       │       ↓
                  │       │   [running] → [done]
                  │       │
                  │       └─ 用户: 「🔄 重新开始」
                  │               ↓
                  │           resume_from_chars=0
                  │               ↓
                  │           从头写（覆盖 partial）
                  │
                  └── 正常完成
                          ↓
                      [done] → SSE: done 事件
```

### 4.3 Cache 三层架构（V0.33 + V0.37）

```
┌─ Application Layer ──────────────────────────────────────┐
│  LLMProvider.complete()                                   │
│    ↓ self._cache.get(key)                                │
└──────────────────────────────────────────────────────────┘
                            ↓
┌─ CacheBackend Protocol ──────────────────────────────────┐
│  get(key) → str | None                                    │
│  set(key, value) → None                                   │
│  size() → int                                             │
│  clear() → None                                           │
│  stats() → dict                                           │
└──────────────────────────────────────────────────────────┘
                ↓                       ↓
┌─ MemoryLRUBackend ──────┐  ┌─ JSONFileBackend ─────────────┐
│  OrderedDict + TTL      │  │  atomic write (temp + rename) │
│  V0.29.0 真 LRU          │  │  + V0.37 跨进程锁 (CacheLock) │
│  V0.33 TTL (过期返回None)│  │  + 启动时过滤过期 + 版本字段   │
│  默认 backend            │  │  cache_backend="json" 时启用  │
└─────────────────────────┘  └────────────────────────────────┘
                                    ↓
                            ┌─ CacheLock ─────────────────┐
                            │  POSIX: fcntl.flock         │
                            │  Windows: msvcrt.locking    │
                            │  unknown: warning + no-op   │
                            └──────────────────────────────┘
```

### 6.4 JSONFileBackend atomic write（V0.33）

```python
def _save(self) -> None:
    """原子写入：temp file + rename"""
    self._path.parent.mkdir(parents=True, exist_ok=True)
    with tempfile.NamedTemporaryFile(
        mode="w", encoding="utf-8",
        dir=self._path.parent,
        prefix=f".{self._path.name}.",
        suffix=".tmp",
        delete=False,
    ) as tmp:
        json.dump({"version": self.FILE_VERSION, "entries": self._entries}, tmp, ensure_ascii=False)
        tmp_path = tmp.name
    Path(tmp_path).replace(self._path)  # atomic rename
```

**注意**：跨进程保护仍需 V0.37 CacheLock（atomic rename 是单机保护）

### 6.5 跨平台文件锁（V0.37）

```python
class CacheLock:
    def __init__(self, target_path: Path) -> None:
        self._backend: str = "none"
        if sys.platform == "win32":
            try: import msvcrt; self._backend = "msvcrt"
            except ImportError: pass
        else:
            try: import fcntl; self._backend = "fcntl"
            except ImportError: pass

    def __enter__(self) -> Self:
        if self._backend == "none": return self
        self._fd = os.open(
            self.lock_path,
            os.O_CREAT | os.O_RDWR | os.O_BINARY,  # ← Windows 必须 O_BINARY
            0o644,
        )
        self._fd = os.fdopen(self._fd, "rb+")
        if self._backend == "fcntl":
            fcntl.flock(self._fd.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
        elif self._backend == "msvcrt":
            msvcrt.locking(self._fd.fileno(), msvcrt.LK_NBLCK, 1)
        return self
```

**Windows 陷阱**：`open(path, "w")` 模式 truncate 会触发 PermissionError（msvcrt 锁住文件时）→ 必须用 `os.open(O_BINARY)` + `os.fdopen("rb+")`
