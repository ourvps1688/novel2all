## 1. 目标

V0.26 留下的 **4 个核心问题**：

| # | 问题 | 影响 |
|---|------|------|
| 1 | **litellm 调 minimax 报 404**（litellm 默认拼 `/v1/chat/completions`，minimax 需要 `/v1/messages`） | WRITING task 完全无法跑 minimax；3 次 V0.26 fallback 试验均失败 |
| 2 | `_anthropic_api_key_for` 是 hardcoded 启发式（基于 "model 名含 anthropic"） | 任何 minimax/DeepSeek 走 anthropic 兼容路径时拿不到 key → 401 |
| 3 | `_call_anthropic_compat` 无 retry；瞬时网络抖动就 500 | 流式写作 4.x 秒长任务中途失败 → 用户必须重试整章 |
| 4 | 旧 WebUI 是 React+Vite SPA，每次前端改动都要 `npm run build` | 文档/教程小修改 → 5 分钟构建 → 用户等待 |

**V0.27-V0.30.3 主旋律**：用透明路由 + 数据驱动 + 工程加固 + 无构建 SPA，把 4 个问题全部根治。

**范围**：
1. 透明路由分流让 minimax 走 httpx 直接调 `/v1/messages`（V0.27）
2. 数据驱动 `_anthropic_api_key_for`（V0.28）
3. 真 LRU cache + tenacity retry + logging 系统化 + provider 单例化 + CLI --model + 错误信息改进（V0.29 全套 6 子版本）
4. WebUI full refactor：HTMX 2.x + Alpine.js 3.x + Jinja2Templates 拆前端 SPA（V0.30 全套 4 子版本 + V0.30.0a stream retry 补丁）

### 3.5 V0.29.0 真 LRU — `ea52a89`

**问题**：V0.24 应用层 cache 是 `dict`，命中后从不淘汰；超 cache_max_size 也不淘汰；V0.29 之前的 cache 命中率测试**永远显示 0**（cache 满后旧的命中项被覆盖）。

**修复**（`core/provider.py`，+45 行）：
- 替换 `dict` 为 `collections.OrderedDict`
- `_cache_get(key)`：命中时 `move_to_end(key)` 更新 LRU 位置
- `_cache_set(key, value)`：超 `cache_max_size` 时 `popitem(last=False)` 淘汰最旧
- 增加 `cache_stats()` 方法：返回 `{hits, misses, size, hit_rate}`

### 3.6 V0.29.1 tenacity retry — `74967ed`

**问题**：`_call_anthropic_compat` 任何瞬时网络抖动（503/504/连接超时）都直接抛 500 给用户，4.x 秒流式任务中途失败。

**修复**（`core/provider.py`，+62 行）：
- 新增 `anthropic_max_retries` / `anthropic_retry_min_wait` / `anthropic_retry_max_wait` 配置（LLMConfig）
- 用 `tenacity` 装饰 `_call_anthropic_compat`：指数 backoff (1s → 2s → 4s → 8s → clamp 10s)
- retry 条件：`httpx.TransportError` + 5xx + 429，**不重试 4xx 客户端错误**
- 可选 `anthropic_retry_log=True` 记录每次重试日志

**测试**：`tests/unit/test_anthropic_retry_v0291.py`（5 个）
- retry_on_transient_error_then_success
- retry_exhausted_raises_last_exception
- no_retry_on_4xx_client_error
- retry_on_429_rate_limit
- no_retry_when_max_retries_is_zero

### 6.1 Transparent 分流原理（V0.27）

```python
def _is_anthropic_compat(self, model_name: str) -> bool:
    """判断 model 是否走 Anthropic Messages API。"""
    model_cfg = self._resolve_model_config(model_name)
    return model_cfg.api_base is not None and "anthropic" in model_cfg.api_base


async def _call_anthropic_compat(
    self, model_name, messages, *, temperature=0.7, max_tokens=2048, api_key=None, api_base=None,
):
    """直接 httpx 调 Anthropic Messages API（绕过 litellm）。"""
    headers = {
        "x-api-key": api_key or os.environ["MINIMAX_API_KEY"],
        "anthropic-version": "2023-06-01",
        "content-type": "application/json",
    }
    # 关键：model 去前缀 + system 顶层 + thinking disabled
    bare_model = model_name.split("/", 1)[-1]  # "minimax/MiniMax-M3" → "MiniMax-M3"
    system_msg, user_msgs = self._split_system_user(messages)
    payload = {
        "model": bare_model,
        "max_tokens": max_tokens,
        "temperature": temperature,
        "system": system_msg,
        "messages": user_msgs,
        "thinking": {"type": "disabled"},  # minimax 不支持
    }
    async with httpx.AsyncClient(timeout=self.config.timeout_seconds) as client:
        for attempt in tenacity.Retrying(
            stop=tenacity.stop_after_attempt(self.config.anthropic_max_retries + 1),
            wait=tenacity.wait_exponential(
                multiplier=self.config.anthropic_retry_min_wait,
                max=self.config.anthropic_retry_max_wait,
            ),
            retry=tenacity.retry_if_exception(self._should_retry),
            reraise=True,
        ):
            with attempt:
                resp = await client.post(f"{api_base}/v1/messages", headers=headers, json=payload)
                resp.raise_for_status()
                data = resp.json()
                return data["content"][0]["text"]
```

### 6.2 真 LRU 实现（V0.29.0）

```python
from collections import OrderedDict

class LLMProvider:
    def __init__(self, config):
        self.config = config
        self._cache: OrderedDict[str, str] = OrderedDict()  # 真 LRU

    def _cache_get(self, key: str) -> str | None:
        if key not in self._cache:
            return None
        self._cache.move_to_end(key)  # 标记为最近使用
        return self._cache[key]

    def _cache_set(self, key: str, value: str) -> None:
        if key in self._cache:
            self._cache.move_to_end(key)
        self._cache[key] = value
        while len(self._cache) > self.config.cache_max_size:
            self._cache.popitem(last=False)  # 淘汰最旧

    def cache_stats(self) -> dict[str, Any]:
        total = self._cache_hits + self._cache_misses
        return {
            "hits": self._cache_hits,
            "misses": self._cache_misses,
            "size": len(self._cache),
            "max_size": self.config.cache_max_size,
            "hit_rate": self._cache_hits / total if total > 0 else 0.0,
            "enabled": self.config.cache_enabled,
        }
```

**前端 Alpine.js 状态机**：
```html
<div x-data="{
    status: 'idle',        // idle | running | done | error
    content: '',
    error: '',
    async start() {
        if (this.status === 'running') return;
        this.status = 'running';
        this.content = '';
        try {
            // HTMX SSE 自动接管 sse-connect + sse-message
            htmx.trigger(this.$refs.form, 'sse-connect');
        } catch (e) {
            this.status = 'error';
            this.error = String(e);
        }
    },
    appendChunk(text) {
        this.content += text;
        this.$refs.output.scrollTop = this.$refs.output.scrollHeight;
    },
    finish() { this.status = 'done'; },
    fail(msg) { this.status = 'error'; this.error = msg; }
}" @sse-message.window="appendChunk($event.detail.data.text)">
    <button @click="start" :disabled="status === 'running'">开始写作</button>
    <div x-ref="output" x-text="content"></div>
    <div x-show="status === 'error'" x-text="error"></div>
</div>
```
